# Құран күнделігі 2.3

Офлайн жұмыс істейтін, телефонға орнатылатын жеке Құран оқу күнделігі (PWA).
Қағида: адам бағдарлама үшін емес, бағдарлама адамға Құран оқуды жеңілдету үшін.

## 2.2 → 2.3 өзгерістері
1. **Оқу бағыты (`readingTrack`)**: `main` (негізгі хатым), `supplementary` (бөлек оқу), `family` (бірлескен хатым).
   «Жалғастыру» тек негізгі бағыттағы соңғы арабша оқуға сүйенеді. Бөлек оқылған беттер оны жылжытпайды.
2. **Бөлек оқуды хатымға қосу — ерікті.** Әдепкіде қосылмайды. Тіркеу кезінде немесе кейін «Күнделік» бөлімінде қосуға/алып тастауға болады.
3. **Хатымдардың тұрақты UUID-і.** Жеке хатым 604 бет қамтылғанда автоматты «аяқталды» деп белгіленеді. Бірлескен хатымдардың өз ID-і бар, жабылғандары тарихта сақталады. Тек `family` бағытымен тіркелген арабша оқу саналады.
4. **Резервтік көшірме:** «Файлға сақтау» және «Бөлісу» (телефонның бөлісу терезесі; қолдау болмаса — файл жүктеледі). Бағдарлама көшірмені өздігінен жасай алмайды.
5. **Екі мұсхаф басылымы** (төмендегі «Бет–аят кестесін тексеру» бөлімін қараңыз).
6. **Migration v3 → v4:** 2.1–2.2 жазбалары жоғалмайды. Ескі жазбалар `main` бағытына, `madani-604` → `madani-1405` басылымына көшеді. Бастапқы енгізу (`rawInput`) өзгертілмейді. Көшіру алдындағы деректер `quran-kundeligi-v2-1-before-v4` кілтімен сақталады. 2.2-дегі бірлескен хатым тағайындаулары «1-бірлескен хатымға» көшеді (2.2-де жеке оқу бірлескенге саналатын — 2.3-те олай емес).
7. Көшірмеден қалпына келтіру: бірдей ID, бірақ әртүрлі мазмұн табылса — ешнәрсе өзгертілмей тоқтайды. Бар деректер ешқашан өшірілмейді.

## Бет–аят кестесін тексеру
| Басылым | Дерек көзі | Лицензия |
|---|---|---|
| `madani-1405` — Мәдина, ескі басылым | quran-meta@7.0.0 (Hafs) | MIT |
| `madani-1441` — Мәдина, 1441 х. (Осман Таһа, Король Фаһд кешені) | quran-qcf4@1.1.0 | JSON бөлігі MIT |

Екі тәуелсіз кесте 604 беттің бәрі бойынша салыстырылды:
- 579 бет бірдей басталады; **25 бет өзгеше**: 121–123, 145, 532–534, 565, 568, 570, 576, 584, 586, 588–590, 592–600.
- quran-qcf4 бойынша барлық 6236 аяттың бетін ескі кестемен салыстырғанда 56 аят басқа бетке түседі — бәрі осы 25 беттің маңында.
- Бұл қате емес, **басылым айырмасы**. 30 параның басталатын беттері екеуінде де бірдей.
- Өз мұсхафыңызды анықтау: **586-бет** «Тәкуир» сүресінің басымен басталса — ескі басылым; «Абаса» сүресінің 41-аятымен басталса — 1441 басылымы.
- Tanzil сайты (tanzil.net/res/text/metadata/quran-data.js) жұмыс ортасынан ашылмады, сондықтан онымен тікелей салыстыру **жасалған жоқ**.

## Сынақ нәтижесі (шынайы күйі)
`tests/scenarios.py` — 18 сценарий, Chromium headless, 390×844 экран: **21/21 тексеріс өтті** (2026-10-25).
Іске қосу: қалтада `python3 -m http.server 8000`, содан кейін `python3 tests/scenarios.py` (Playwright керек).

**Тексерілмеген:** нақты Android және iPhone құрылғылары; офлайн режим (service worker тек HTTPS-те қосылады, тест localhost-та жүрді); «Бөлісу» терезесі; iOS-та деректердің ұзақ сақталуы.

## GitHub Pages-ке орналастыру
1. Жаңа Public репозиторий → `tests` қалтасынан басқа файлдарды түбірге жүктеу.
2. Settings → Pages → Branch `main`, `/ (root)` → Save.
3. Телефонда сілтемені ашып, «Басты экранға қосу» / «Қолданбаны орнату».
4. Ұшақ режимінде ашылатынын тексеру.

**Жаңарту:** `sw.js` ішіндегі `CACHE` атауының нөмірін өзгертпесеңіз, телефон ескі нұсқаны көрсете береді.
